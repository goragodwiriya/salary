# Salary — ระบบเงินเดือนออนไลน์

ระบบจัดการเงินเดือนพนักงานผ่านเว็บ นำเข้าข้อมูลเงินเดือนรายเดือนจากไฟล์ CSV คำนวณภาษีหัก ณ ที่จ่ายและประกันสังคมให้อัตโนมัติ ผ่านการอนุมัติ แล้วให้พนักงานแต่ละคนเข้ามาดูและพิมพ์สลิปเงินเดือนของตัวเองได้ สร้างบน [Now.js](https://nowjs.net) (ฝั่ง client) และ [Kotchasan](https://www.kotchasan.com) (ฝั่ง PHP)

*Web-based payroll for small and medium organisations: import monthly salary data from CSV, auto-calculate Thai withholding tax and social security, approve, and let each employee view and print their own pay slip.*

> Version: **7.0.4** | License: MIT

## ✨ คุณสมบัติ / Features

- **สลิปเงินเดือนของฉัน**: พนักงานทุกคนดูประวัติเงินเดือนของตัวเองย้อนหลังรายปี และสั่งพิมพ์สลิปได้ (เห็นเฉพาะรายการที่อนุมัติแล้ว)
- **นำเข้าข้อมูลพนักงาน (CSV)**: สร้างบัญชีพนักงานใหม่หรือปรับปรุงบัญชีเดิม พร้อมบันทึกแผนกและตำแหน่งให้อัตโนมัติ
- **นำเข้าเงินเดือนรายเดือน (CSV)**: เลือกปี/เดือน แล้วอัปโหลดไฟล์ ถ้าเดือนนั้นมีข้อมูลแล้วจะปรับปรุงรายการเดิม ไม่สร้างซ้ำ
- **คำนวณอัตโนมัติ**: ภาษีหัก ณ ที่จ่ายตามวิธีของกรมสรรพากร (หักค่าใช้จ่าย ค่าลดหย่อน และแยกภาษีของโบนัส) หรืออัตราคงที่ และประกันสังคมทั้งส่วนพนักงานและนายจ้าง
- **ค่าล่วงเวลาจากชั่วโมง**: กรอกจำนวนชั่วโมง ระบบคิดเงินจากฐานเงินเดือนและตัวคูณที่ตั้งไว้ หรือกรอกเป็นจำนวนเงินเองก็ได้
- **ใช้กับโปรแกรมเงินเดือนเดิมได้**: ปิดการคำนวณอัตโนมัติ แล้วนำเข้าประกันสังคมและภาษีที่คำนวณไว้แล้ว ใช้ระบบนี้แจกสลิปอย่างเดียว
- **อนุมัติก่อนเผยแพร่**: ผู้มีสิทธิ์อนุมัติ คำนวณใหม่ ส่งแจ้งเตือน หรือลบรายการได้ทีละหลายรายการ
- **แดชบอร์ด**: การ์ดสรุป (จำนวนพนักงาน, ยอดเงินเดือนเดือนนี้, เงินเดือนเฉลี่ย, รายการรออนุมัติ) และกราฟแนวโน้มเงินเดือน, เงินเดือนเฉลี่ยและจำนวนพนักงานรายแผนก, การกระจายของเงินเดือน
- **ส่งออก CSV**: ดาวน์โหลดรายการเงินเดือนตามตัวกรองที่เลือก
- **แจ้งเตือน**: อีเมล, LINE และ Telegram เมื่ออนุมัติหรือส่งสลิป
- **ผู้ใช้และสิทธิ์**: กำหนดสิทธิ์รายโมดูล เข้าสู่ระบบด้วย Google, Facebook, LINE หรือ Telegram ได้
- **หลายภาษา**: ไทย / อังกฤษ
- **รองรับ PWA**: ติดตั้งเป็นแอปบนมือถือได้ (`manifest.json`, `service-worker.js`)

## 📋 ความต้องการของระบบ / Requirements

- PHP 7.4 ขึ้นไป พร้อมส่วนขยาย `pdo_mysql`, `mbstring`, `zlib`, `xml`, `gd`
- MySQL 5.5.3+ หรือ MariaDB 5.5+ (ต้องรองรับ `utf8mb4`)
- Apache ที่เปิด `mod_rewrite` และอนุญาต `.htaccess` (`AllowOverride All`)
- Node.js เฉพาะกรณีต้อง build ไฟล์ frontend ใหม่ (ไฟล์ใน `Now/dist/` พร้อมใช้งานแล้ว)

## 🚀 การติดตั้ง / Installation

1. Clone โปรเจ็ค แล้ววางไว้ใน document root ของเว็บเซิร์ฟเวอร์

   ```bash
   git clone https://github.com/goragodwiriya/salary.git
   ```

2. สร้างฐานข้อมูลเปล่า (แนะนำ `utf8mb4`)
3. ให้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์ `settings/` และ `datas/` ได้

   ```bash
   mkdir -p settings datas
   chmod -R 775 settings datas
   ```

4. เปิด `http://your-domain/install/` แล้วทำตามขั้นตอน (ตรวจสอบระบบ → ตั้งค่าฐานข้อมูล → สร้างผู้ดูแลระบบ)
5. เข้าสู่ระบบด้วยบัญชีผู้ดูแลที่สร้างไว้

> 🔒 **หลังติดตั้งเสร็จ** ให้ลบหรือจำกัดการเข้าถึงโฟลเดอร์ `install/` บนเซิร์ฟเวอร์จริง

### ติดตั้งผ่านบรรทัดคำสั่ง

รันจาก root ของโปรเจ็คเสมอ

```bash
# ติดตั้งใหม่ลงฐานข้อมูลเปล่า
php install/cli-fresh.php <dbname> [prefix] --admin=<email> --password=<pass>

# ตรวจสอบฐานข้อมูลหลังติดตั้งหรือปรับรุ่น
php install/cli-verify.php <dbname> [prefix]
```

### การปรับรุ่น / Upgrading

**สำรองฐานข้อมูลก่อนทุกครั้ง** จากนั้นวางไฟล์รุ่นใหม่ทับ (`settings/` และ `datas/` จะไม่ถูกแตะ) แล้วเปิด `/install/` อีกครั้ง ตัวปรับรุ่นจะตรวจเงื่อนไขก่อนแตะฐานข้อมูล และหยุดพร้อมบอกสาเหตุถ้าเงื่อนไขไม่ครบ หรือปรับรุ่นจากบรรทัดคำสั่ง:

```bash
php install/cli-upgrade.php <admin-username> <admin-password> --confirm-backup
```

## 🧭 ขั้นตอนการใช้งาน / Workflow

### 1. นำเข้าข้อมูลพนักงาน

เมนู **ตั้งค่า → เงินเดือน → นำเข้าข้อมูลพนักงาน** (ผู้ดูแลระบบเท่านั้น) คอลัมน์ของไฟล์:

| คอลัมน์ | หมายเหตุ |
|---|---|
| ชื่อ (`Name`) | ชื่อ-นามสกุล |
| เลขประชาชน (`Identification No.`) | ใช้จับคู่พนักงานเดิม |
| อีเมล (`Email`) | ใช้เป็นชื่อผู้ใช้ และจับคู่พนักงานเดิม |
| เพศ (`Sex`) | |
| แผนก (`Department`) | สร้างหมวดหมู่ให้ถ้ายังไม่มี |
| ตำแหน่ง (`Position`) | สร้างหมวดหมู่ให้ถ้ายังไม่มี |

ระบบจับคู่พนักงานด้วยเลขประชาชนหรืออีเมล ถ้าไม่พบจะสร้างบัญชีใหม่ ดูตัวอย่างได้ที่ [`employees.csv`](employees.csv) (ข้อมูลสมมติ)

> ⚠️ บัญชีที่สร้างจากการนำเข้าใช้รหัสผ่านเริ่มต้น **`123456`** แจ้งให้พนักงานเปลี่ยนรหัสผ่านทันทีหลังเข้าระบบครั้งแรก

### 2. นำเข้าเงินเดือนรายเดือน

เมนู **เงินเดือน → นำเข้าข้อมูลเงินเดือน** เลือกปีและเดือน แล้วอัปโหลดไฟล์ (ดาวน์โหลดไฟล์ตัวอย่างได้จากหน้าเดียวกัน)

| คอลัมน์ | หมายเหตุ |
|---|---|
| ชื่อ (`Name`) | |
| เลขประชาชน (`Identification No.`) | ใช้จับคู่พนักงาน ถ้าไม่พบในระบบจะข้ามแถวนั้น |
| ฐานเงินเดือน (`Basic Salary`) | |
| เบี้ยเลี้ยง (`Allowance`) | |
| ชั่วโมงล่วงเวลา (`Overtime Hours`) | ไม่บังคับ ถ้ากรอก ระบบคิดค่าล่วงเวลาให้และไม่ใช้คอลัมน์ถัดไป |
| ค่าล่วงเวลา (`Overtime`) | จำนวนเงิน (บาท) ใช้เมื่อไม่ได้กรอกชั่วโมง |
| โบนัส (`Bonus`) | |
| หักอื่นๆ (`Deduction`) | |
| ประกันสังคม (`Social Security`) | เฉพาะเมื่อปิดการคำนวณอัตโนมัติ (บังคับในโหมดนี้) |
| ภาษีเงินได้ (`Income Tax`) | เฉพาะเมื่อปิดการคำนวณอัตโนมัติ (บังคับในโหมดนี้) |
| หมายเหตุ (`Remark`) | ไม่บังคับ |

หัวคอลัมน์ใช้ได้ทั้งภาษาไทยและภาษาอังกฤษ ไฟล์ตัวอย่างและรายการคอลัมน์บนหน้านำเข้าจะเปลี่ยนตามการตั้งค่าให้เอง ส่วนการเข้ารหัสของไฟล์ (เช่น UTF-8 หรือ TIS-620 จาก Excel) ตั้งได้ที่หน้าตั้งค่าโมดูล

### 3. ตรวจสอบและอนุมัติ

เมนู **เงินเดือน → รายการเงินเดือน** กรองตามปี/เดือน/สถานะ แล้วเลือกหลายรายการเพื่อ **อนุมัติ**, **คำนวณใหม่**, **ส่งอีเมล** หรือ **ลบ** ได้พร้อมกัน ถ้าปิดการอนุมัติไว้ รายการใหม่จะอนุมัติทันที

รายการที่บันทึกแล้วจะไม่เปลี่ยนเองเมื่อแก้การตั้งค่า (เช่น อัตราประกันสังคม ค่าลดหย่อน หรือตัวคูณค่าล่วงเวลา) ให้เลือกรายการแล้วกด **คำนวณใหม่**

### 4. พนักงานดูสลิป

พนักงานเข้าเมนู **เงินเดือน → สลิปของฉัน** เพื่อดูรายการที่อนุมัติแล้วและสั่งพิมพ์สลิป ระบบตรวจว่าเป็นสลิปของผู้ที่ล็อกอินอยู่ทุกครั้ง

## 🧮 การคำนวณ / Calculation

ทุกช่องทางที่บันทึกเงินเดือน (ฟอร์ม, นำเข้า CSV, คำนวณใหม่) ใช้สูตรเดียวกันใน [`modules/salary/models/calculator.php`](modules/salary/models/calculator.php)

```
ค่าแรงต่อชั่วโมง = ฐานเงินเดือน ÷ (วันทำงานต่อเดือน × ชั่วโมงทำงานต่อวัน)
ค่าล่วงเวลา     = ค่าแรงต่อชั่วโมง × ตัวคูณค่าล่วงเวลา × ชั่วโมงล่วงเวลา   (เมื่อกรอกชั่วโมง)
รายได้รวม       = ฐานเงินเดือน + เบี้ยเลี้ยง + ค่าล่วงเวลา + โบนัส
ประกันสังคม     = min(รายได้รวม, เพดานฐานประกันสังคม) × อัตราส่วนพนักงาน
เงินได้สุทธิ     = รายได้รวม − ภาษี − ประกันสังคม − หักอื่นๆ
```

### ภาษีหัก ณ ที่จ่าย

**แบบขั้นบันได** (`salary_tax` = 0) ใช้วิธีประมาณเงินได้ทั้งปีของกรมสรรพากร

```
เงินได้ทั้งปี     = (ฐานเงินเดือน + เบี้ยเลี้ยง + ค่าล่วงเวลา) × 12
ค่าใช้จ่าย       = min(เงินได้ทั้งปี × 50%, 100,000)
เงินได้สุทธิทั้งปี = เงินได้ทั้งปี − ค่าใช้จ่าย − ค่าลดหย่อนต่อปี − (ประกันสังคม + หักอื่นๆ) × 12
ภาษีต่อเดือน     = ขั้นบันได(เงินได้สุทธิทั้งปี) ÷ 12
```

โบนัสเป็นเงินได้ครั้งเดียว จึงไม่นำไปคูณ 12 แต่หักภาษีส่วนที่เพิ่มขึ้นเพราะโบนัสทั้งจำนวนในเดือนที่จ่าย คือ ขั้นบันได(เงินได้ทั้งปี + โบนัส) − ขั้นบันได(เงินได้ทั้งปี)

| เงินได้สุทธิต่อปี (บาท) | อัตรา |
|---|---|
| 0 – 150,000 | ยกเว้น |
| 150,001 – 300,000 | 5% |
| 300,001 – 500,000 | 10% |
| 500,001 – 750,000 | 15% |
| 750,001 – 1,000,000 | 20% |
| 1,000,001 – 2,000,000 | 25% |
| 2,000,001 – 5,000,000 | 30% |
| เกิน 5,000,000 | 35% |

ตัวอย่างด้วยค่าตั้งปริยาย: เงินเดือน 30,000 บาท หักประกันสังคม 750 บาท เงินได้สุทธิทั้งปี = 360,000 − 100,000 − 60,000 − 9,000 = 191,000 บาท ภาษีทั้งปี 2,050 บาท หักเดือนละ **170.83** บาท

**แบบอัตราคงที่** (`salary_tax` > 0) เช่น 3%: ภาษี = (รายได้รวม − ประกันสังคม − หักอื่นๆ) × อัตรา

> ℹ️ ค่าลดหย่อนเป็นค่าเดียวที่ใช้กับพนักงานทุกคน (ค่าเริ่มต้น 60,000 บาท = ค่าลดหย่อนส่วนตัว) ยังไม่รองรับค่าลดหย่อนรายคนตามแบบ ล.ย.01 (คู่สมรส บุตร ประกันชีวิต กองทุนสำรองเลี้ยงชีพ ฯลฯ) พนักงานที่มีค่าลดหย่อนมากกว่านี้จะถูกหักภาษีสูงกว่าจริง ถ้าต้องการตัวเลขรายคนที่แม่นยำ ให้ปิดการคำนวณอัตโนมัติแล้วนำเข้าภาษีที่คำนวณจากโปรแกรมอื่น

### ปิดการคำนวณอัตโนมัติ

ตั้ง `salary_auto_calculate` เป็น "ไม่ใช่" เมื่อคำนวณเงินเดือนด้วยโปรแกรมอื่นอยู่แล้ว ระบบจะใช้ประกันสังคมและภาษีที่กรอกในฟอร์มหรือนำเข้าจาก CSV ตามจริง และคำนวณเฉพาะค่าล่วงเวลา (ถ้ากรอกชั่วโมง) กับเงินได้สุทธิ

## ⚙️ การตั้งค่า / Configuration

ค่าของโมดูลแก้ได้ที่ **ตั้งค่า → เงินเดือน → ตั้งค่าโมดูล** และถูกบันทึกลง `settings/config.php`

| คีย์ | คำอธิบาย | ค่าเริ่มต้น |
|---|---|---|
| `salary_tax` | อัตราภาษีคงที่ (%) `0` = คิดแบบขั้นบันได | `0` |
| `salary_tax_allowance` | ค่าลดหย่อนต่อปีที่ใช้กับพนักงานทุกคน (เฉพาะแบบขั้นบันได) | `60000` |
| `salary_social` | ประกันสังคมส่วนพนักงาน (%) | `5` |
| `salary_social_employer` | ประกันสังคมส่วนนายจ้าง (%) | `5` |
| `salary_social_max` | เพดานฐานเงินเดือนที่ใช้คิดประกันสังคม | `15000` |
| `salary_overtime_rate` | ตัวคูณค่าล่วงเวลา (เท่าของค่าแรงต่อชั่วโมง) | `1.5` |
| `salary_working_days` | วันทำงานต่อเดือน ใช้หาค่าแรงต่อชั่วโมง | `22` |
| `salary_working_hours` | ชั่วโมงทำงานต่อวัน ใช้หาค่าแรงต่อชั่วโมง | `8` |
| `salary_require_approval` | ต้องอนุมัติก่อนพนักงานจะเห็นสลิป | `1` |
| `salary_auto_calculate` | คำนวณประกันสังคมและภาษีให้ `0` = ใช้ค่าที่กรอกหรือนำเข้า | `1` |
| `salary_notification` | แจ้งเตือนเมื่ออนุมัติ | `1` |
| `salary_csv_language` | การเข้ารหัสของไฟล์ CSV ที่นำเข้า | `UTF-8` |
| `salary_employee_status` | สถานะสมาชิกของพนักงานที่สร้างจากการนำเข้า | `0` |

ช่องทางแจ้งเตือน (อีเมล, LINE, Telegram, SMS) ตั้งได้จากเมนูตั้งค่าของระบบ

> ⚠️ ไฟล์ใน `settings/` มีรหัสผ่านฐานข้อมูล, API token และ JWT secret ส่วน `datas/` มีไฟล์ที่ผู้ใช้อัปโหลด **ห้าม commit ทั้งสองโฟลเดอร์** (ระบุไว้ใน `.gitignore` แล้ว)

### สิทธิ์ / Permissions

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| สมาชิกทั่วไป | ดูและพิมพ์สลิปของตัวเอง |
| `can_approve_salary` | ดูรายการเงินเดือนของทุกคน และอนุมัติ |
| `can_manage_salary` | ดูรายการ, เพิ่ม/แก้ไข, นำเข้าเงินเดือนจาก CSV |
| `can_config` | ตั้งค่าโมดูล |
| ผู้ดูแลระบบ | นำเข้าข้อมูลพนักงาน (สร้าง/แก้ไขบัญชีสมาชิก) |

## 🗂️ โครงสร้างโปรเจ็ค / Structure

```
Gcms/          คลาสแกนของแอป (Api, Controller, Line, Telegram, ...)
Kotchasan/     PHP framework
Now/           Now.js frontend framework (ซอร์สและ dist/)
modules/
  salary/      เงินเดือน: นำเข้า คำนวณ อนุมัติ สลิป แดชบอร์ด
  index/       ผู้ใช้ สิทธิ์ ภาษา การตั้งค่าระบบ
  export/      หน้าสั่งพิมพ์และส่งออกข้อมูล
  download/    ไฟล์ดาวน์โหลด
  timeline/    ไทม์ไลน์กิจกรรม
templates/     หน้า HTML ของแต่ละโมดูล
install/       ตัวติดตั้งและตัวปรับรุ่น (เว็บและ CLI) และสคีมา SQL
language/      ไฟล์ภาษา (th, en)
line/ telegram/  webhook ของ LINE และ Telegram
settings/      ไฟล์ตั้งค่า (สร้างตอนติดตั้ง ไม่อยู่ใน git)
datas/         ไฟล์อัปโหลด แคช และ log (ไม่อยู่ใน git)
```
